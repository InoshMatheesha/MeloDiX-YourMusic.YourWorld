# Melodix (Rust / Tauri) — Build Guide

This is the Rust rewrite shell of Moodex/Melodix. It replaces **Electron**
(which bundled a full Chromium engine, ~500 MB–1 GB RAM) with **Tauri**, which
uses the **WebView2** runtime already present on Windows. Expected RAM in use:
**~150–250 MB** instead of 600 MB–1 GB, and the installer shrinks from ~150 MB
to ~10 MB + the bundled Node runtime.

## Architecture (staged port)

```
┌─────────────────────────────────────────────┐
│  Melodix.exe  (Rust / Tauri)                 │
│                                              │
│  ├─ WebView2 window  ◀── webroot/ (the UI,   │
│  │                        reused 1:1 from    │
│  │                        the Electron app)  │
│  │   └─ moodex-shim.js recreates             │
│  │       window.electronAPI on Tauri         │
│  │                                           │
│  ├─ Rust commands  (window, dialogs, config, │
│  │                  cache, storage)          │
│  │                                           │
│  └─ Node sidecar  ──▶ sidecar/server/server.js
│        (bundled node.exe)   the 8,500-line   │
│        127.0.0.1:<port>     search / stream /│
│                             lyrics backend,  │
│                             reused unchanged │
└─────────────────────────────────────────────┘
```

The Node sidecar is launched by Rust, prints its listening port on stdout,
and Rust hands that port to the UI. The server's token is generated by Rust
and passed to the sidecar via the `MOODEX_TOKEN` env var.

## Prerequisites

- **Rust** (GNU toolchain): `stable-x86_64-pc-windows-gnu`
- A GNU linker + `windres` on PATH — this project was built with **MSYS2
  mingw64** (`C:\msys64\mingw64\bin`): gcc, dlltool, ar, windres.
- **Node.js** (only to run the Tauri CLI; the app bundles its own node.exe).
- Tauri CLI (installed locally via `npm install`).

## Build

```powershell
# from this folder
$env:Path = "$env:USERPROFILE\.cargo\bin;C:\msys64\mingw64\bin;$env:Path"
npm install            # installs @tauri-apps/cli (once)
npx tauri build        # release build + NSIS installer
```

Outputs:
- `src-tauri/target/release/melodix.exe` — the app binary
- `src-tauri/target/release/bundle/nsis/Melodix_2.0.9_x64-setup.exe` — installer

## Run in dev

```powershell
$env:Path = "$env:USERPROFILE\.cargo\bin;C:\msys64\mingw64\bin;$env:Path"
npx tauri dev
```

## Notes / staged roadmap

The UI and the entire `/api/*` backend work. Native extras that were in the
Electron main process are currently graceful no-ops in `moodex-shim.js` and are
the next things to port to Rust:

- Discord Rich Presence
- Auto-updater (electron-updater → Tauri updater)
- System tray + global media keys
- Themes / plugins management
- Google / YouTube Music OAuth import
- Mini player & lyrics overlay windows
- Local-folder metadata scanning (currently returns file paths only)

`yt-dlp` and `ffmpeg` are resolved the same way as the Electron app (PATH or the
data-dir `bin/` folder) — they are not bundled, matching the original.
